# PhishGuard browser extension (Chrome, Manifest V3)

Right-click any link, choose "Check link with PhishGuard", and get a notification with the verdict. The toolbar popup checks the current tab or a pasted link. It calls the public PhishGuard API; nothing is stored.

Install (no store needed): open `chrome://extensions`, turn on Developer mode, click "Load unpacked", pick this `extension` folder.
